# Boba Bliss Spintex

Build a vibrant, playful, high-converting bubble tea shop website for a boba shop located on Spintex Road, Accra, Ghana. Every order flows through WhatsApp — there is no cart/checkout system. Each menu item has an "Order Now" button that opens a WhatsApp chat pre-filled with a message naming that specific drink and size (e.g., "Hi! I'd like to order a Large Brown Sugar Milk Tea Boba"). Use this placeholder WhatsApp number throughout: [0548787608/0506324680].

Overall Vibe

Fun, youthful, Instagram-worthy, dopamine-inducing — this should feel like a treat, not a utility site. High-converting means: strong visual hierarchy, bold CTAs repeated often, minimal friction between "see drink" and "order it."

Design Language (style direction, not literal copy)

Section-by-section mood shift: instead of one flat background, let the page transition through 2–3 distinct color zones as the user scrolls (e.g., a rich warm brown/caramel top section → a soft peachy-orange middle → a punchy pink lower section), each divided by an organic "drip" or wave shape transition rather than a hard line

Hero: bold oversized wordmark-style headline, a rotating/carousel showcase of 3 "Best Seller" drinks with a "BEST SELLER" badge on each, drink photo on a clean cup mockup, small floating icon accents (fruit, boba pearls, tea leaf) scattered around for texture

Big personality typography: mix a bold display font for headlines with a playful script/handwritten accent font for taglines

Personalization touch: include a section showing a cup with a customer's name written on it (e.g., "Made For You") to sell the idea of a personalized ordering experience

Craveworthy flavors section: a fun illustrated section with fruit/ingredient artwork (banana, pineapple, grape, orange, paint-splash color accents) building appetite appeal before the full menu

Floating decorative elements: boba pearls, tea cup icons, and splash shapes used as scattered background texture throughout (not just in one section)

Site Structure

1. Hero

Bold headline establishing the shop's personality (fun, energetic — write original copy, don't reuse another brand's exact tagline)

Subheadline: something like "70+ handcrafted bubble tea drinks, frappes, refreshers & more — Spintex Road, Accra"

Best-seller carousel (3–5 rotating drinks, each with photo + "BEST SELLER" badge + price)

Primary CTA: "View Full Menu" (scrolls to menu) + persistent floating WhatsApp order button that follows as user scrolls

2. Brand Story ("More Than Just Boba" — style, original copy)

Short emotional paragraph on what makes this shop different — crafted with love, adventure in every sip, etc. (write fresh copy in this spirit)

3. "Sweeten Your Day, Your Way"

Section explaining customizable sweetness levels — let customers choose light, medium, or full sugar

4. Personalization / "Made For You"

Visual section with a cup mock-up showing a customer's name on it, communicating that drinks can be personalized

5. Craveworthy Flavors

Illustrated fruit/flavor showcase section building appetite appeal, transitioning into the menu

6. Full Menu (searchable)

Include a search bar ("Search drinks...") at the top of the menu section. Organize by category exactly as below. Every drink card includes: an appealing photo of the drink, name, Large price, Medium price, and an "Order Now" WhatsApp button (green, white WhatsApp icon).

IMPORTANT — generate an appetizing, realistic-looking bubble tea photo for every single item (distinct cup, distinct drink color/toppings matching the flavor name) so no two drinks look identical.
